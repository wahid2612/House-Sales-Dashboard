# House-Sales-Dashboard
This project presents an interactive dashboard developed in Tableau, based on a housing dataset containing detailed property information. Each row in the dataset represents a unique house listing, such as Prices bedrooms, bathrooms, etc

🏘️ Housing Market Analysis – Tableau Dashboard
This project offers a comprehensive visual analysis of housing data using Tableau, focusing on property sales in Washington. The dataset includes features like price, size, condition, location, and construction year, allowing deep insights into real estate trends.

📈 Key Visualizations
📉 Average Price Over Time: A line chart visualizes the average house sale prices across time, highlighting seasonal or market trends.

🗺️ Geographic Price Distribution: A map shows the average home prices across various Washington locations using color gradients, helping identify high and low-value areas.

📊 Histograms: Price, bedroom, and bathroom distributions are visualized to understand market range and common property configurations.

🔥 Heatmap of View vs Condition: This matrix cross-compares how property views (e.g., excellent, good, fair) align with condition ratings (e.g., excellent, average, worn-out) to show how visual appeal and physical state affect pricing.

📅 Calendar View: A detailed calendar chart presents average house prices for each day, month, and selected year—useful for observing seasonal buying patterns.

📋 Final Dashboard & Story
All visualizations are integrated into a dynamic dashboard, enabling users to interact with filters like year, location, or property features. A storyboard walks viewers through key insights, making the narrative both engaging and data-driven.

This project demonstrates the power of data visualization in turning raw housing data into actionable insights for buyers, sellers, and analysts in the real estate domain.
